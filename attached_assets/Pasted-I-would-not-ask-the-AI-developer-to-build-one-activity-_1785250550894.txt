I would not ask the AI developer to build **one activity**. Instead, ask it to build the **Interactive Classroom Engine**, then implement the first activity (**Math Escape Challenge**) as the reference implementation.

This ensures every future activity (Bingo, Relay Race, Gallery Walk, etc.) reuses the same architecture.

---

# Prompt for AI Developer

## Task #38 — Interactive Classroom Engine (Phase 1)

### Objective

Build the first version of **Iqra Interactive Classroom**, an AI-powered classroom experience that helps teachers deliver engaging lessons instead of simply generating text.

This is **NOT** a worksheet generator.

This is **NOT** a PDF generator.

This is a classroom presentation engine with teacher guidance, presentation mode, printable resources, timers, answer reveals, and future gamification support.

The first implementation should support **Grade 10 Mathematics** and include one complete activity:

> **Math Escape Challenge**

The architecture must be reusable for every future activity and every subject.

---

# Design Principles

The classroom experience should follow these principles:

* Mobile-first UI (Flutter)
* Teacher controls the activity
* Students view the presentation (phone/tablet/projector)
* Minimal teacher preparation
* One-tap presentation mode
* AI generates structured data, never long paragraphs
* Every activity follows a standard schema
* Future activities reuse the same engine

# Technical Requirements

* Flutter architecture using reusable widgets.
* Separate the **activity engine**, **presentation engine**, **teacher controls**, and **activity data model** into independent modules.
* Support offline playback after the activity is generated.
* Persist activities locally and synchronize them with the user's workspace.
* Design the engine so future support for animations, audio, leaderboards, QR codes, and live student participation can be added without refactoring the core architecture.

---

# Definition of Done

The feature is complete when a teacher can:

1. Open **Interactive Classroom**.
2. Choose **Math Escape Challenge**.
3. Configure the activity (time, difficulty, group type, objective).
4. Generate the activity.
5. Preview it.
6. Launch Presentation Mode.
7. Control the lesson using next, previous, hint, answer reveal, and timer.
8. View private teacher notes.
9. Print resources.
10. Save the activity to their workspace.

**Important:** Focus on building a reusable **Interactive Classroom Engine**, not a single hardcoded activity. The Math Escape Challenge is the first reference implementation that validates the architecture and establishes the standard for all future interactive classroom experiences.
