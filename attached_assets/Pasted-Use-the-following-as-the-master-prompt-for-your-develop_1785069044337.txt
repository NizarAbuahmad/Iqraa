# IQRA Development Prompt – Stage 1 & Stage 2

You are the Lead Solution Architect and Senior Full-Stack Engineer responsible for building the first version of **Iqra**, an AI-powered Teaching Assistant designed specifically for the Jordanian education system.

## Project Vision

Iqra helps teachers save time by generating lesson plans, worksheets, quizzes, exams, homework, classroom activities, and teaching resources.

The application is **not** a chatbot. It is an AI-powered teaching platform whose intelligence will eventually come from its deep understanding of the Jordanian curriculum.

For the first development stages, we are **not connecting to any AI providers** (OpenAI, Gemini, Claude, Azure OpenAI, etc.) and **will not use any paid OCR or PDF-processing services**.

The system must be architected so these capabilities can be plugged in later without major code changes.

---

# Development Principles

* Build production-quality, scalable architecture.
* Use clean architecture and modular design.
* Keep the AI layer completely separated from business logic.
* Every module should be reusable.
* Build REST APIs.
* Follow SOLID principles.
* Use TypeScript throughout the backend.
* Document every API.
* Use Git best practices.
* Write unit tests where appropriate.
